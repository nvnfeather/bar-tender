# Bar-Tender

A browser-only bar-chart workbench using **real Python and Matplotlib** through Pyodide.

## Publish on GitHub Pages

1. Extract the ZIP on your computer.
2. Upload **all files** in this folder to the root of your GitHub repository. Keep the filenames unchanged. Include the JavaScript worker and Python renderer.
3. Commit the files.
4. In the repository, open Settings → Pages.
5. Choose Deploy from a branch → main → / (root) → Save.
6. Open the website link shown by GitHub Pages once deployment finishes.

## Using it

The workspace starts empty. Click **New graph**, choose categories or categories and series, and enter a mean and SD for each row (the default). For raw samples, paste a single Excel row or column of numbers into the Mean field to automatically switch that category to raw data, or select Raw data and paste into a measurement field. The Excel number-array panel also lets you select a target category; it replaces only that row’s measurements, without changing other categories. Raw samples use sample SD (n − 1). Python recomputes raw means and SD for the actual chart. All charts, error bars, legends, control limits, SVG exports and PNG clipboard images are generated by Matplotlib.

Click **Copy PNG** to copy the currently displayed graph (or combined figure) as a 200 DPI PNG with a white background. Paste it into PowerPoint, Word or another image-capable app. Clipboard copying requires the HTTPS website, a supported browser and clipboard permission. The button is disabled until the current chart finishes rendering.

Python and Matplotlib start downloading in the background as soon as the page opens. You can create graphs and enter data while they load. Initialization may take a minute depending on your connection; charts render when the engine is ready and reuse it while the tab remains open. An internet connection and access to cdn.jsdelivr.net are required to initialize the chart engine. Measurements remain in the visitor's browser and are never sent to a plotting server.

Save projects before closing or refreshing. No automatic data persistence is provided.

## Files

- index.html — dashboard
- style.css — dashboard appearance
- app.js — editor and project handling
- matplotlib-engine.js — browser-to-worker bridge
- matplotlib-worker.js — loads Python and Matplotlib in a background worker
- plot_renderer.py — actual Matplotlib plotting implementation
- bar-tender-logo.png — logo
- FONT-LICENSE.txt — DejaVu font attribution
- .nojekyll — tells GitHub Pages to serve these files directly

Serve through GitHub Pages or an HTTP server. Opening index.html directly with file:// does not support loading the Python worker.

The runtime is pinned to Pyodide 0.27.7, which supplies Matplotlib 3.8.4. No server, API key, Python installation, npm build, or GitHub Actions configuration is needed.
